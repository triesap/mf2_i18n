# Security Policy

## Supported Versions

`mf2_i18n` is pre-1.0. Security fixes are released for the latest published
version.

## Reporting A Vulnerability

Report security issues privately by email to Tyson Lupul at `tyson@radroots.org`.

Please include the affected version, a short impact summary, and reproduction
details when available. Do not open a public issue for an unpatched vulnerability.
